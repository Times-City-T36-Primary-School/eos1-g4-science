# EOS 1 – G4 Science Revision Trail

Vinschool Times City T36 Primary School – Advanced Program

A revision trail for Grade 4 science (Cambridge Primary Science Stage 5), End of Semester 1.
Nine stops, each with Words, See it, Games, Notes and a Mini test. English with Vietnamese support.

Open it here: https://times-city-t36-primary-school.github.io/eos1-g4-science/

The whole app is the single file `index.html`. Progress is saved in the browser of each device;
a progress code (name menu on the map) moves stars to another device.
